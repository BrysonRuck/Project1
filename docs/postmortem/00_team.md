# Project 01 Post Mortem - [Group 03 / Project1]

## Context
[What we set out to build. What actually shipped.]
The project that we set out to build was basically a tinder for food, so you could find food near you within a certain distance to whatever you had sent and you would be able to swipe left or right to say if you wanted to eat there or not.  this didn't really work out in the long term since the API we had used for one couldn't give us photos of the place unless we paid money for the API, so all we had was the location and the name.  we also didn't end up making it shows the locations one at a time and instead just made it so that you could see a list that could be randomized showing all the restaurants in the area. Due to this the application went from a swipable app to something that was based off a list style of choice.
